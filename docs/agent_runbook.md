# 每日编辑执行说明

## 开始前

读取当前主信源、编辑规则、搜索清单，以及最近成功日报的事件记录与截止时间。仓库快照供迁移与离线参考；若能读取持久文件中的较新版本，以较新版本为准。

当次生成唯一批次和截止时间。主窗口从上次成功截止开始；没有记录时检查前24小时。新闻回看7日，学术回看30日。只有日精度时，不编造精确24/72小时归属。

## 必须实际执行的覆盖

- 内地31省级地区各做专项和综合政策两项，逐项保留实际查询。标题不含低空的场景开放、数字经济、服务业、交通、应急、文旅政策也筛正文与附件。
- 上海与长三角深入检查，不能替代全国覆盖。
- 企业覆盖研发、取证、订单性质、融资、交付与经营；母集团和子公司分开。
- 学术同时搜索中英文，结合中文数据库、期刊原站、Crossref、OpenAlex、arXiv；算法论文按产业、治理、运行等相关性筛选。
- 标准从公告和目录发现，读详情、原公告及附件，按标准号和年代号去重；区分草案、发布、备案、实施与废止，国际工作项目不写成已发布标准。
- 海外检索覆盖美国、欧洲、英国、澳大利亚及亚洲市场，分监管、企业、设施与运营主题。保留原始日期、币种、许可阶段和企业自述归属。
- 每日另做FC01-CN、FC01-EN、FC02-CN、FC02-EN、FC03、FC04六项独立检索，覆盖飞行汽车、flying car、特斯拉、Tesla、Roadster及马斯克相关声明。主式与逐行补充见[独立检索说明](search_coverage.md)，不要求新闻标题含eVTOL。重要命中逐条登记采用、待核或不采用原因，避免线索只停留在搜索回执。
- 采购分国家平台、省市平台、采购主体/代理/国企栏目和聚合线索四层，逐项检查查询、详情、附件及分页。按项目号、包号、公告类型和版本跟踪更正。

主检索式必做。补充词分行执行；正文中的执行说明不能当作查询词。计划中`instruction`是操作提示，`query_or_entry`仍须人工识别为检索式或原站入口，不能全部自动当作搜索。

## 核验与证据

每条准备采用的消息至少核查：发布主体、原文发布与事件日期、原始出处、关键数字和单位、阶段、条件、截止及来源冲突。搜索摘要不是原文，页面能打开也不等于全文读完。

政策重要结论追官方文件。采购预算、限价与成交额分开；意见截止不写成投标截止，更正响应截止不推定文件获取期同延。意向、签约、测试、适航审定、生产许可与商业运行批准分别表达。

学术按编辑规则v1.10：先在内部说清问题、作者判断和证据，再生成一个自然段。正文通常80—150字、必要时至200字。相关性、因果、推导与模拟分开；研究含义有原文支持，关键限制具体。完整阅读卡、页码、表图锚点与A/B/C等级留在内部；AI新笔记为waiting-review。只有摘要时注明，只有搜索片段时不刊登。

## 状态与记录

状态使用：未执行、已检有新增、已检无合格新增、已发现待核、读取失败、不在本轮计划。

每项记录任务ID、对象ID、词组ID、源ID、批次、实际时间、实际查询或入口、证据链接、发现数、已读原文、采用事件与缺口。合并查询响应不分摊为伪造的逐式发现数。未知数留空。完成查询不等于完成原文、附件和分页验收；脚本记录是编辑申报，并非外部事实的自动证明。

## 成稿与交接

标题并列最重要的2—3条不同进展，末尾附低空日报与日期。今日总结一段2—3句话、100—180字。栏目按编辑规则排列，空栏省略。较新合格消息优先，不设总条数上限。

选稿先评估政策、监管与企业实质进展，优先用于标题、总结和正文；境外同类动态同样适用。采购继续完整检索核查，同项目零散配套公告合并，常规或无实质变化的标讯移入内部跟踪，不按日重复刊登。保留重大新阶段、关键结果、实质条件变化及确有价值的临期提醒，并记录采用理由。不得用固定比例或金额门槛替代编辑判断；合并不抹去分项目的编号、金额及期限。

公开正文仅含新闻、真实日期、出处和必要的预印本/征求意见属性。补收、采集窗口、任务覆盖和待核说明留在独立编辑附记。每期选1—2张已实际打开、与新闻对应且使用条件允许的原图；保留署名和水印。

输出公开MD、HTML与独立附记，检查图片内嵌、加粗及链接。保存截止、事件键、论文DOI/版本、标准号及采购项目关联，供下一次去重。保存成功不等于完成编辑审核。最终发布由账号拥有者决定。
